# Настройка Google OAuth для YouTube Private Uploader

Каждый пользователь создаёт собственный OAuth-клиент типа **Desktop app**. Публичный установщик не содержит учётных данных. Для авторизации приложение открывает системный браузер и принимает ответ через локальный адрес.

## Подготовка в Google Cloud

1. Откройте [Google Cloud Console](https://console.cloud.google.com/), создайте или выберите свой проект и включите **YouTube Data API v3** в библиотеке API.
2. Настройте экран согласия OAuth для своего проекта. Для личного Google-аккаунта используйте аудиторию **External**. Если проект находится в режиме **Testing**, добавьте свой аккаунт в список тестовых пользователей.
3. Добавьте два scope, которые приложение действительно запрашивает:
   - `https://www.googleapis.com/auth/youtube.upload` — загрузка видео;
   - `https://www.googleapis.com/auth/youtube.force-ssl` — получение списка плейлистов и добавление видео в плейлист. Этот scope даёт более широкие права, чем одна загрузка; проверьте экран согласия перед авторизацией.
4. В разделе учётных данных создайте **OAuth client ID** с типом **Desktop app** и скачайте его JSON-файл.
5. Переименуйте файл в `client_secret.json` и поместите в папку `config` рядом с `YouTubePrivateUploader.exe`. При установке по умолчанию это `D:\Apps\YouTubePrivateUploader\config\client_secret.json`, а если диска D нет — `C:\Apps\YouTubePrivateUploader\config\client_secret.json`. При запуске из исходников используйте `config\client_secret.json` в корне проекта.

Не добавляйте этот JSON и файл `token.json` из каталога данных установки в Git, архивы или обращения за поддержкой. Установщик и репозиторий их не содержат.

## Первый запуск и смена аккаунта

Выберите папку и видео, заполните поля и начните загрузку. При первом обращении к YouTube Data API откроется браузер Google. Выберите аккаунт нужного канала и внимательно проверьте запрошенные права. После успешного входа токен сохраняется в `%APPDATA%\YouTubePrivateUploader\installations\<идентификатор установки>\token.json`.

Если нужно сменить канал, используйте в приложении «Сбросить авторизацию». Старый локальный токен будет удалён, а следующая загрузка откроет новый вход. Для работы с плейлистами после обновления scope также может потребоваться повторная авторизация.

В режиме Google Cloud **Testing** доступ ограничен перечисленными тестовыми пользователями, а авторизация тестового пользователя может истечь через семь дней. Для более широкого распространения OAuth-проекта Google может потребовать проверку приложения и scopes. Публичный исходный код этой программы сам по себе не заменяет настройку или проверку вашего OAuth-проекта.

Официальные источники: [OAuth для настольных приложений YouTube Data API](https://developers.google.com/youtube/v3/guides/auth/installed-apps), [аудитория и режим Testing](https://support.google.com/cloud/answer/15549945), [проверка OAuth-приложения](https://support.google.com/cloud/answer/13461325).
