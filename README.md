<h1 align="center">YouTube Private Uploader</h1>
<p align="center">Загрузка видео на свой канал YouTube с обязательным статусом Private.</p>
<p align="center"><a href="README.en.md">English</a> · <a href="https://github.com/Frommer-droid/Youtube-upload/releases/latest">Последний релиз</a></p>

Приложение выбирает последний видеофайл в рабочей папке, собирает название и описание из редактируемых шаблонов, загружает видео через YouTube Data API v3 и при необходимости добавляет его в плейлист. Статус загруженного видео всегда **Private**. Сделать ролик публичным можно только вручную в YouTube Studio.

## Возможности

- После выбора рабочей папки — автоматический выбор последнего видео и подходящей обложки JPEG/PNG. Поддерживаются имя видео, распространённые имена обложек и прежний `Cover-G`; при неоднозначности обложку можно выбрать вручную.
- Редактируемые шаблоны названия и описания, поле «Перевод» с переменной `{translator}`, ссылки Telegram/MAX, текст стихотворения и предпросмотр результата.
- Загрузка с отображением прогресса и повторами при временных сетевых сбоях; установка обложки и необязательное добавление в плейлист.
- Сохранение полей, шаблонов, масштаба и положения окна между запусками.
- При загрузке следующего видео введённые поля сохраняются; кнопка «Очистить название, перевод и ссылки» сбрасывает только название песни, перевод и ссылки Telegram/MAX.
- Кнопки для открытия видео и YouTube Studio после загрузки.

## Установка и первый запуск

1. Скачайте установщик со страницы [последнего релиза](https://github.com/Frommer-droid/Youtube-upload/releases/latest) и запустите его. Для готового приложения Python не нужен.
2. Создайте **собственный** OAuth-клиент типа Desktop app в Google Cloud, включите YouTube Data API v3 и скачайте JSON. Краткий порядок приведён в [SETUP_GOOGLE.md](SETUP_GOOGLE.md).
3. Сохраните файл как `client_secret.json` в папке `config` установленного приложения: `D:\Apps\YouTubePrivateUploader\config\client_secret.json` для установки по умолчанию. Если на компьютере нет диска D, установщик предложит `C:\Apps\YouTubePrivateUploader\config\client_secret.json`. Установщик не содержит учётных данных.
4. Выберите в приложении рабочую папку с видео и при желании обложкой JPEG/PNG. Можно выбрать «Рабочий стол»: приложение откроет рабочий стол текущего пользователя, даже если он перенесён. Введите название, проверьте предпросмотр и нажмите «Загрузить на YouTube».
5. При первом обращении к API завершите авторизацию в системном браузере. После загрузки откройте YouTube Studio, если хотите изменить статус Private вручную.

Для плейлистов приложение запрашивает дополнительный OAuth scope `youtube.force-ssl`. В Google Cloud режим Testing ограничивает круг пользователей и срок действия авторизации; подробности и ссылки на документацию Google есть в [руководстве по настройке](SETUP_GOOGLE.md).

## Запуск из исходников

Нужны Windows x64, Python 3.12 и собственный `config\client_secret.json`. Сборка и неинтерактивный smoke проверены на Windows 11; Windows 10 в текущем релизе отдельно не проверялась.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe YouTubePrivateUploader.py
```

Тесты и воспроизводимая сборка используют проектное окружение:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe -m ruff check src tests Build_Tools --no-cache
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

`build.ps1` ограничивает `PATH` доверенными каталогами, проверяет происхождение DLL и запускает скрытую неинтерактивную проверку собранного приложения. Подробности для разработчика — в [DEVELOPER.md](DEVELOPER.md).

## Данные и ограничения

- OAuth-файл располагается рядом с приложением, а токен, настройки и личные шаблоны — в `%APPDATA%\YouTubePrivateUploader\installations\<идентификатор установки>\`. Каждая новая установка начинает с пустых личных данных; прежние файлы не удаляются. Эти файлы не входят в репозиторий или публичный установщик.
- Приложение не меняет статус видео на Public через API и не автоматизирует YouTube Studio.
- Реальная загрузка требует рабочего OAuth-клиента, канала YouTube и квоты API. Автотесты не выполняют сетевую загрузку.
