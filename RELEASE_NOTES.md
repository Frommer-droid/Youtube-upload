# История изменений (Release Notes)

## Версия 1.1.8 (2026-09-29)

*Имя переводчика можно вводить отдельно и использовать в шаблоне описания.*

### ✨ Новые возможности

- Под названием песни добавлено поле «Перевод». Значение сохраняется между запусками и подставляется в описание через `{translator}`.
- Стандартный шаблон описания содержит строку «Перевод: {translator}»; при пустом поле она не появляется в готовом описании. Старые пользовательские шаблоны без новой переменной продолжают работать.

### 🐛 Исправления ошибок

- Кнопка «Очистить название, перевод и ссылки» очищает также поле «Перевод», сохраняя теги, стихотворение и параметры публикации.
- При выборе другого видео перевод остаётся в форме вместе с остальными введёнными данными.

## Версия 1.1.7 (2026-09-29)

*Повторная загрузка сохраняет введённые данные, а очистка затрагивает только название песни и ссылки.*

### 🐛 Исправления ошибок

- Кнопка «Загрузить другое видео» больше не стирает название песни, ссылки, теги и стихотворение; категория, плейлист и параметры публикации также сохраняются.
- Кнопка «Очистить название и ссылки» удаляет только название песни и ссылки Telegram/MAX. Остальные поля и параметры остаются без изменений.

## Версия 1.1.6 (2026-09-28)

*Рабочая папка и обложка выбираются по универсальным правилам для каждого пользователя.*

### 🐛 Исправления ошибок

- Первый запуск по-прежнему оставляет папку и видео пустыми. Диалог выбора папки открывается на рабочем столе текущего пользователя, включая перенесённый рабочий стол.
- Автопоиск обложки принимает JPEG/PNG с именем выбранного видео, стандартные имена (`thumbnail`, `thumb`, `cover`, `poster`, `обложка`) и прежнее `Cover-G`. Если в папке только одно изображение, подходит любое имя; при неоднозначности приложение предлагает ручной выбор.
- После загрузки следующего ролика приложение остаётся в выбранной рабочей папке. Ручной выбор обложки сохраняется при смене видео в этой папке.
- Файлы `.jpeg` передаются в YouTube с правильным типом `image/jpeg`.

## Версия 1.1.5 (2026-09-28)

*Новая установка открывается без личных данных и выбранного видео.*

### 🐛 Исправления ошибок

- Установщик создаёт идентификатор установки. Настройки, шаблоны, OAuth-токен и логи хранятся отдельно для каждой установки; старые файлы в `%APPDATA%\YouTubePrivateUploader\` не удаляются и не подставляются в новую форму.
- При первом запуске рабочая папка и видео не выбраны. Автопоиск последнего видео начинается только после выбора папки пользователем.
- При следующих запусках этой же установки введённые поля и выбранная папка восстанавливаются без перезаписи во время инициализации.

## Версия 1.1.0 (2026-09-28)

*Приложение подготовлено для самостоятельной установки: нейтральные шаблоны, обновлённый интерфейс, проверяемая сборка и установщик без личных данных.*

### ✨ Новые возможности

- Отдельная вкладка предпросмотра показывает итоговое название и описание до загрузки.
- Иконки действий и приложения согласованы с интерфейсом; настройка масштаба и
  положение окна сохраняются между запусками.
- Подготовлен установщик для текущего пользователя с собственной настройкой Google OAuth.

### 🐛 Исправления ошибок

- Повторная загрузка того же видео больше не блокируется старой отметкой истории.
- После успешной загрузки остаются только действия с результатом и очистка полей;
  предыдущий прогресс и кнопки загрузки скрываются.
- Восстановление размеров и положения окна учитывает доступную область экрана и
  сохраняет обычную геометрию отдельно от развёрнутого состояния.

### 🎨 Интерфейс

- Пять вкладок объединяют загрузку, стихотворение, шаблоны, предпросмотр и настройки.
- Палитра и состояния элементов приведены к One Dark.

### 🛡️ Безопасность

- Новая установка использует нейтральные шаблоны без личных ссылок и реквизитов;
  ранее сохранённые пользователем шаблоны остаются в его локальных настройках.
- Сборка ограничивает `PATH`, отклоняет чужие DLL, проверяет происхождение native
  runtime и запускает неинтерактивный frozen smoke. Публичный установщик не
  включает OAuth-файл, токен, настройки или логи.
- Закреплены исправленные версии `idna` и `protobuf` в составе приложения;
  обновлена зависимость `Pygments` для инструментов разработки.

### 📚 Документация

- Добавлены README на русском и английском, инструкции самостоятельной настройки
  Google OAuth и лицензия MIT для кода владельца.

## Версия 1.0.0 (2026-08-16)

*Первый официальный релиз: загрузка ролика на YouTube-канал строго как Private.*

### 🎬 Рабочий процесс

- Рабочая папка по умолчанию — «Рабочий стол»: автоматически берутся последний
  видеофайл по дате создания и обложка `Cover-G.*` (jpg/jpeg/png)
- Поле «Название песни»: заголовок собирается по шаблону
  «Песня на слова стихотворения Шарля Бодлера «{song}»»
- Описание собирается из фиксированного блока + ссылок Telegram/MAX + текста
  стихотворения; шаблоны названия и описания редактируются в отдельных вкладках
- Счётчики символов, живое предпросмотр заголовка и описания, проверка полей
  до загрузки

### 🧩 Интерфейс

- 5 вкладок: «Загрузка», «Шаблон названия», «Шаблон описания», «Стихотворение»,
  «Настройки»
- Автосохранение полей формы между запусками + кнопка «Очистить все поля»
- Плейлисты: выбор плейлиста канала из выпадающего списка, автоматическое
  добавление видео после загрузки, запоминание выбора
- Масштаб интерфейса 50–150% через выпадающий список (авто от экрана/DPI +
  ручная поправка), тексты масштабируются пропорционально
- Безопасная геометрия окна: размер, позиция и состояние «развёрнуто»
  запоминаются в настройках, окно никогда не выходит за пределы экрана

### 🔒 Надёжность и приватность

- Только официальный YouTube Data API v3 (scope `youtube.upload` +
  `youtube.force-ssl`), никакой автоматизации браузера
- Статус видео **всегда Private** — зашит в коде
- Resumable upload по частям, прогресс в %, автоматические повторы при сбоях
  сети (exponential backoff)
- Автоматическая установка обложки после загрузки видео
- Защита от случайной двойной загрузки одной папки (`.youtube-upload.json`)
- Один раз открывшийся браузер Google для авторизации; токен хранится
  в `%APPDATA%\YouTubePrivateUploader\`
- Логирование в `%APPDATA%\YouTubePrivateUploader\logs\`

### 🧰 Для разработчика

- Python 3.12 + PySide6, тёмная QSS-тема, русские переводы Qt
- 115 автотестов (pytest), сборка через PyInstaller (`Build_Tools` + `post_build.py`)
